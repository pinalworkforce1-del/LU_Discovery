# Level Up — Discovery

Interactive Discovery module for Level Up. Learners explore strengths, values, purpose, support needs, and a next quest through narrated scenes, accessible exploration cards, native reflections, saved device progress, a coach snapshot, and a completion certificate.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

The included workflow builds and deploys the site whenever `main` is updated. In repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

Participant progress is currently stored in the browser. Supabase authentication and cross-device persistence are planned as the next platform layer.
